# ToDoListApp

Project Description 
I created an interactive To-Do List Website using HTML CSS, and JavaScript. It is meant to keep task in one place organized while stayed focused with a timer.

Features
- Add, edit, and delete tasks.
- Filters tasks based on priority.
- Marks tasks as completed or restores them.
- Saved tasked using localStorage.
- Responsive for computers and phones.

Technology Used 
- HTML
- CSS
- JavaScript
- localStorage
